TO RUN APP

Make sure Django is running first:
bash# In Django terminal
cd D:\government_asset_platform
venv\Scripts\activate
python manage.py runserver 0.0.0.0:8000

Important — 0.0.0.0:8000 instead of just runserver
This makes Django listen on all network interfaces — not just localhost. Without this your phone cannot reach it even on the same WiFi. Your laptop IP 192.168.100.18 only works when Django binds to 0.0.0.0.

Then run Flutter:
bash# In Flutter terminal
cd C:\Users\Hemed\govasset_mobile

HOW TO RUN
# Step 1 — Deactivate whatever venv is currently active
deactivate

# Step 2 — Go to your correct project folder
cd D:\government_asset_platform

# Step 3 — Activate the correct venv
venv\Scripts\activate

# Step 4 — Confirm you are in the right venv
# You should see (venv) PS D:\government_asset_platform>
# NOT (venv) PS D:\massstore-backend>

# Step 5 — Confirm Django version is correct
python -c "import django; print(django.__version__)"

# Step 6 — Run the server
python manage.py runserver 0.0.0.0:8000
